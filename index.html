Damos el siguiente paso: llevar la aplicación del entorno de desarrollo a producción, empaquetarla y dejarla lista para el cliente.

Objetivo y temas clave: Generar la compilación de producción del frontend (npm run build en React) y del backend (WAR de Spring Boot), contenerizar los servicios con Dockerfile y Docker Compose, desplegar la aplicación y marcar la versión estable con un Tag de release (v1.0.0) en Git.
